# AI-Based Suspicious Transaction Detection System

A prototype system for detecting suspicious transactions on mobile money platforms in Zimbabwe. Developed as the final year project for the Diploma in Cybersecurity, Chinhoyi University of Technology.

**Author:** Munesuishe Fambisai (CYA278)

## Features

- Machine learning risk scoring (Logistic Regression, Decision Tree and Random Forest) of every transaction
- Low, Medium and High risk levels with configurable thresholds
- Sanctions screening of sender and recipient names
- Real-time behavioural features: one-hour transaction velocity and 24-hour cumulative volume
- Alert queue with reason codes and an investigation workflow
- Real-time screening API for mobile money platforms (`POST /api/v1/evaluate-transaction`)
- Role-based login (Administrator and Analyst) with bcrypt password hashing
- Audit trail of logins, evaluations and configuration changes
- Optional AI compliance assistant and case summaries

## Technology

Python, Flask, Flask-SQLAlchemy (SQLite by default, MySQL through `DATABASE_URL`), scikit-learn, pandas, NumPy, HTML, CSS and JavaScript.

## Project structure

| File | Purpose |
|---|---|
| `app.py` | Flask application, routes, transaction evaluation and screening API |
| `models.py` | Database models: users, transactions, alerts, audit logs, sanctions |
| `config.py` | Configuration, model paths and risk thresholds |
| `train_models.py` | Generates the simulated dataset and trains the three classifiers |
| `explain.py` | Reason codes showing which features raised a transaction's risk score |
| `seed.py` | Creates the database, demo accounts, sanctions list and scored transactions |
| `ai_assistant.py` | Optional AI compliance assistant |
| `verify_api.py` | Checks the screening API end to end |
| `templates/`, `static/` | Web interface |

## Running the system

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

python train_models.py           # simulated dataset + trained models in data/
python seed.py                   # database with demo accounts and transactions
python app.py                    # http://127.0.0.1:5002
```

### Optional AI features

The AI assistant and case summaries need an API key (`ANTHROPIC_API_KEY`, `NVIDIA_NIM_API_KEY` or `OPENROUTER_API_KEY`). Without one, the rest of the system works normally and case summaries use the built-in rule-based engine.

## Screening API example

```bash
curl -X POST http://127.0.0.1:5002/api/v1/evaluate-transaction \
  -H "Content-Type: application/json" \
  -d '{"sender_wallet": "+263771234567", "recipient_wallet": "+263778888888",
       "amount": 250.00, "currency": "USD", "payment_type": "P2P",
       "is_unfamiliar": 1, "is_new_device": 0, "account_age_days": 180}'
```

The response contains a decision: `APPROVED` (low risk), `FLAGGED` (medium risk) or `BLOCKED` (high risk or sanctions match).

## Data

All transactions are synthetic, generated by `train_models.py`. No real customer data is used.
