Pluggable API Gateway

Connect mobile money systems (EcoCash, OneMoney) for real-time transaction screening.

Real-Time Screening API

Mobile money platforms submit raw transaction payloads to this endpoint. The screening engine computes transaction velocity and daily volume in real-time from past logs, runs the active machine learning classifier, saves the record, and returns a transaction recommendation.

POST /api/v1/evaluate-transaction

Request Payloads (JSON)

{ "sender_wallet": "+263771234567", "recipient_wallet": "+263778888888", "amount": 250.00, "currency": "USD", "payment_type": "P2P", "is_unfamiliar": 1, "is_new_device": 0, "account_age_days": 180 }

Response Schema (JSON)

{ "success": true, "transaction_id": "TX-101004", "decision": "APPROVED", "risk_score": 0.0845, "risk_level": "LOW", "reasons": [], "evaluation_timestamp": "2026-08-28 13:58:12", "active_model_used": "Random Forest" }

Decision Recommendations

  • APPROVED (Low Risk): Transaction is cleared immediately.
  • FLAGGED (Medium Risk): Transaction completes, but triggers a dashboard alert for analyst review.
  • BLOCKED (High Risk): Transaction is stopped. Outbound wallets may be temporarily locked pending review.
